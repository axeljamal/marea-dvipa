# Development log

## Values
- Design an original signature inspired by historical traditions and local heritage, and always credit the origins.
- Make the project resourceful, interactive and fun, creative, intelligent and original.
- A signature design must be reproducible on any visual medium; never render the source object (such as metal jewellery) literally.
- Keep every exploration, including the rejected ones, and improve them as we learn from great designers.
- Connect APIs only with approval.
